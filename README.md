# prog-mobile

Este repositório é dedicado à matéria de Programação Mobile, com foco no uso de Dart e Flutter.

Aqui será o local onde os exercícios da disciplina serão organizados e compartilhados ao longo do curso.

## Objetivo

- Praticar conceitos de programação mobile;
- Desenvolver aplicações utilizando Dart e Flutter;
- Registrar e acompanhar os exercícios realizados na disciplina.
